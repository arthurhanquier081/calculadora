# Calculadora Fullstack 🧮

Projeto de uma aplicação web de calculadora simples desenvolvida com arquitetura Fullstack, separando as responsabilidades de interface (Frontend) e de processamento lógico/API (Backend).

## 🎨 Atualização Visual (Feature: Alteração de Cor)

Esta versão da branch inclui o novo design da interface:
- **Plano de fundo e card:** Atualizados para um tema escuro e elegante (Dark Slate/Blue).
- **Botão de Calcular:** Destacado na cor verde (`#28a745`) com efeito de transição para melhor usabilidade e contraste.

## 🚀 Tecnologias Utilizadas

* **Backend:** Node.js, Express, Cors
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Controle de Versão:** Git e GitHub

## 📁 Estrutura do Projeto

* `public/index.html`: Interface visual (Frontend)
* `calculadora.js`: Servidor e rotas da API (Backend)
* `package.json`: Gerenciador de dependências do Node.js
* `README.md`: Documentação do projeto

## 🔧 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/arthurhanquier081/calculadora.git](https://github.com/arthurhanquier081/calculadora.git)

   Entre na pasta do projeto:
   cd calculadora
   
   Instale as dependências:
   npm install
   
   Inicie o servidor Backend:
   node calculadora.js
   
   Acesse no navegador:
   Abra http://localhost:3000
